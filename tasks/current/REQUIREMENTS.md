# Задания нет

Текущего задания нет. Этот файл — заглушка: сюда пользователь кладёт новую
задачу (2–10 строк идеи достаточно) или, после закрытия предыдущего, —
готовую спеку с планом фаз.

Когда появится задание, оркестратор:

1. Прочитает этот файл.
2. Если внутри сырая идея — запустит скилл `task-spec` (отдельная сессия
   `spec-writer` исследует зону и напишет полную спеку по шаблону
   `.qwen/skills/task-spec/TEMPLATE.md`).
3. Если уже готовая спека с планом фаз — стартует исполнение по фазам
   через `backend-dev` (см. [QWEN.md](../../QWEN.md) раздел «Агентный
   режим» и [AGENTS.md](../../AGENTS.md) раздел «Зоны и проверки»).

Закрытые задания лежат в `tasks/NNN-<slug>/` — пока папка пуста.
